# Modelos 3D realistas: origem e licença

Conferido em 20/11/2026.

**Poly Haven** (https://polyhaven.com/license)
- Todos os modelos são **CC0**: domínio público, uso comercial liberado, sem crédito obrigatório.
- Foram baixados uma vez para este repositório, e o pipeline não usa a API deles na produção.

**NASA 3D Resources** (https://github.com/nasa/NASA-3D-Resources)
- A NASA declara os modelos "livres e sem direito autoral".
- Siga as diretrizes de uso da NASA: **não sugerir que a NASA apoia o perfil ou um produto** e não usar o logotipo da NASA como marca.

**Como o pipeline usa:** o Diretor escreve `"objeto": "modelo:<nome>"`, e o código copia para o projeto só os modelos usados.
